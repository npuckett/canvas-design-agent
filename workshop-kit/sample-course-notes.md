# Sample Course Notes

Use this sample if you do not have course material ready.

Course: ART 101 - Introduction to Drawing
Term: Fall 2026
Meeting time: Tuesdays 1:00-4:00 PM
Room: Studio 302
Instructor: Prof. Sarah Chen
Office hours: Thursdays 2:00-4:00 PM, Room 305

Page type: Week 3 module page
Week title: Value Studies - Light And Shadow

Overview:
This week introduces value as a way to describe light, shadow, volume, and space. Students will practice building value scales, observing light direction, and translating simple forms into tonal drawings.

Learning goals:
- Identify highlight, midtone, core shadow, reflected light, and cast shadow
- Build a smooth graphite value scale
- Use value to create the illusion of form
- Apply feedback from a quick peer critique

Agenda:
1. Warm-up drawing: five-minute sphere studies
2. Mini lecture: value and light logic
3. Demo: graphite value scale
4. Studio exercise: still life with three objects
5. Peer critique and wrap-up

Due before next class:
- Complete one finished value study from the still life setup
- Bring sketchbook with three additional value studies
- Read chapter 4 from the course drawing handbook

Materials:
- Graphite pencils from 2H to 6B
- Kneaded eraser
- White vinyl eraser
- Drawing paper
- Blending stump, optional

Reminder:
Midterm project proposal is due Week 5.
