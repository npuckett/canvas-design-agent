# Canvas Design Agent Workshop Kit

This folder is a portable workshop packet for faculty who will use a web-based AI chat to create Canvas LMS pages. It is designed to be copied into a separate workshop materials repository.

The default workshop path is Microsoft Copilot in a browser. ChatGPT and Claude can also work if participants can upload or paste the skill file.

## What To Copy

Copy this entire `workshop-kit/` folder into the workshop repository.

Included files:

- `SKILL.md` - portable copy of the Canvas Design Agent skill file
- `participant-start-here.md` - one-page participant workflow
- `copilot-upload-guide.md` - Microsoft Copilot instructions
- `chatgpt-claude-guide.md` - alternate web AI instructions
- `starter-prompts.md` - copy/paste prompts for common Canvas pages
- `sample-course-notes.md` - fallback content for participants without prepared material
- `canvas-paste-checklist.md` - before/after Canvas checklist
- `troubleshooting.md` - common workshop problems and fixes
- `media-url-guide.md` - image, link, and iframe URL guidance
- `sample-output-review-checklist.md` - how to inspect generated HTML without reading all code
- `facilitator-run-of-show.md` - suggested timing and support flow

## Before Each Workshop

1. Refresh `SKILL.md` from the canonical file at `.github/SKILL.md` in the main Canvas Design Agent repo.
2. Confirm which Microsoft Copilot surface participants will use.
3. Confirm whether participants can upload files. If not, use the paste fallback in `copilot-upload-guide.md`.
4. Test one sample page by uploading or pasting `SKILL.md`, using `sample-course-notes.md`, and pasting the output into a Canvas sandbox.
5. Replace any institution-specific placeholders in these handouts.

## Canonical Source

The canonical skill file lives at `.github/SKILL.md` in the Canvas Design Agent repository. The copy in this folder is for workshop portability only.

## Workshop Goal

The first success metric is simple: every participant leaves with one Canvas page generated from their own plain-text course material and successfully saved in Canvas.
