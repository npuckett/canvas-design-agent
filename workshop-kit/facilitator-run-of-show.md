# Facilitator Run Of Show

This is a suggested flow for a 75-90 minute workshop.

## Before Participants Arrive

- Confirm the approved Microsoft Copilot URL or app.
- Confirm file upload is enabled. If not, use the paste fallback.
- Test `SKILL.md` with `sample-course-notes.md`.
- Open a Canvas sandbox page for live demonstration.
- Have `participant-start-here.md` and `starter-prompts.md` ready to share.

## 0-10 Minutes: Orientation

- Explain the goal: one working Canvas page from plain text.
- Show that participants do not need to write HTML.
- Name the limits: Canvas strips scripts, style blocks, SVG, and some CSS.

## 10-25 Minutes: Live Demo

1. Open Microsoft Copilot.
2. Upload or paste `SKILL.md`.
3. Paste `sample-course-notes.md`.
4. Use the starter prompt.
5. Copy the HTML output.
6. Paste into Canvas HTML editor view.
7. Save and review.

## 25-55 Minutes: Participant Build Time

- Participants use their own content or `sample-course-notes.md`.
- Encourage simple pages first.
- Ask participants to use the checklist before pasting.

## 55-75 Minutes: Troubleshooting And Iteration

Common triage order:

1. Did they upload or paste `SKILL.md`?
2. Did the AI output an HTML fragment or a full page?
3. Did Canvas strip formatting after save?
4. Are image URLs absolute?
5. Is the layout too complex for mobile?

## Optional Extension

- Show themes and element IDs.
- Show Component Sketching Mode: ask for 3-4 ways to display one schedule, rubric, resource list, or callout.
- Pick one option tag, such as `OPTION-B: D05-S01 Schedule Grid`, and ask for a focused revision.
- Show how the chosen option tag can feed into a later full-page prompt.
- Show a course-specific template.
- Show how to revise the page by sending the current HTML back to the AI with a specific request.

## Closing

- Remind participants to save their original plain-text prompt.
- Remind them to test links, images, and mobile readability.
- Share the troubleshooting handout for follow-up.
