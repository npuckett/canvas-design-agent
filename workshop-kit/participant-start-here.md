# Start Here: Make One Canvas Page

Use this workflow if you are new to AI tools, HTML, or Canvas page design.

## What You Need

- Access to Microsoft Copilot, ChatGPT, or Claude
- The file `SKILL.md` from this workshop folder
- Some course content, such as notes, a syllabus section, a weekly module, or an assignment description
- A Canvas page where you can click Edit

## The Basic Workflow

1. Open Microsoft Copilot in your browser.
2. Start a new chat.
3. Upload `SKILL.md`. If upload is not available, open `SKILL.md`, select all text, copy it, and paste it into the chat.
4. Paste your course content into the same chat.
5. Ask Copilot to transform it into Canvas-ready HTML.
6. Copy the generated HTML output.
7. Open your Canvas page and click Edit.
8. Click the HTML editor button. It usually looks like `</>` and may be under a more-options menu.
9. Paste the generated HTML.
10. Save the page and review it.

## Copy This Starter Request

```text
Use the uploaded Canvas Design Agent skill file. Transform my course content into a Canvas-ready HTML fragment.

Requirements:
- Use only inline styles.
- Do not include html, head, or body tags.
- Do not wrap the answer in a markdown code fence.
- Use accessible headings, readable colors, descriptive links, and Canvas-safe layout.
- Before the HTML, briefly tell me what layout and elements you chose.
```

Then paste your course content below that request.

## If You Do Not Know What Style You Want

Say this:

```text
I do not know which design elements to choose. Please use the default Clean Modern style, a readable single-column layout, and choose appropriate Canvas-safe elements for my content.
```

## After Saving In Canvas

Check that:

- The page still looks formatted after saving.
- The heading order makes sense.
- Links work.
- Images load, if you used images.
- Important information is visible without opening a collapsed section.
- The page is readable on a narrow/mobile view.
