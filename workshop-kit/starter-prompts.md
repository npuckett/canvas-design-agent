# Starter Prompts

Use these prompts after uploading or pasting `SKILL.md` into Microsoft Copilot, ChatGPT, or Claude.

## Rough Notes To Canvas Page

```text
Use the Canvas Design Agent skill. Transform my rough course notes into a Canvas-ready HTML fragment.

Use the default Clean Modern style unless my notes suggest another mood. Choose a readable single-column layout. Use tables for schedules or rubrics when helpful. Use collapsible sections only for supplemental information.

Accessibility requirements: one clear h1, ordered headings, readable contrast, descriptive link text, and alt text placeholders for any images.

Output only a Canvas HTML fragment. No html, head, body, style, script, SVG, or markdown code fence.

Here are my notes:
```
