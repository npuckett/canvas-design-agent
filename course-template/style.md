## Recurring structure

Every **class page** should have, in order:

1. Header banner with class number, topic, and date
2. "Agenda" — ordered list
3. Main content area
4. "Resources" — collapsible section (C01)
5. "Next Class" — collapsible section (C01)

Every **assignment** should have, in order:

1. "About" section
2. "Deliverables" — bulleted list
3. "Grading" — table, when rubric details exist

## Voice and conventions

- Dates written as: `Wednesday September 9`
- Course referred to as: (short course name)
- Always include alt text on images; link text is descriptive, never
  "click here"
