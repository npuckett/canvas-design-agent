What you can give the skill, what it can produce, and which output type to ask for in different teaching situations.

The Basic Exchange

Canvas Design Agent turns course content into Canvas-safe HTML. You provide the skill file plus an input type, and the agent returns an output type that respects Canvas Rich Content Editor constraints.

Download SKILL.md Choose a Method

Most common path: upload SKILL.md, paste rough course notes, ask for Canvas-ready HTML source, then paste that source into Canvas's HTML editor view.

Input Types

Rough Notes

Plain text, pasted syllabus sections, bullet lists, agendas, or assignment descriptions. Best for fast first drafts.

Markdown Prompt Files

Reusable .md files with headings, content, style notes, and output expectations. Best for repeatable course production.

Element ID Requests

Optional control handles such as V05, D05, or C01. Use them when you want specific catalog elements.

Course Templates

Style preferences, colors, recurring sections, page types, and layout patterns that should repeat across many pages.

Media URLs

Absolute image, video, iframe, or GitHub Pages URLs. Canvas cannot use relative paths from your computer.

Existing Canvas HTML

Paste an existing page as a reference when you want revision, cleanup, consistency, or style extraction.

Output Types

Output Use It For Ask For
Canvas HTML Fragment The default paste-ready output for Canvas pages, assignments, announcements, and module content. "Create Canvas-ready HTML source with inline styles. Use a downloadable canvas-fragment.html file or artifact when possible."
Component Sketch Options Comparing several ways to present one schedule, rubric, resource list, callout, or data block. "Use Component Sketching Mode and show 3-4 tagged options."
Reusable Prompt File Creating a clean markdown source that can generate the same kind of page again later. "Turn these notes into a reusable prompt file before generating HTML."
Course Page Template Defining repeated page structure, colors, headers, sections, and layout choices across a course. "Create a course-specific template I can reuse for weekly pages."
Revision Prompt Fixing generated HTML after Canvas strips something, a layout breaks, or content changes. "Revise this for Canvas-safe inline HTML and keep the same content."

Common Page Types

Weekly Module Page

Header, goals, agenda, resources, due dates, next steps. Start from class-page.md.

Assignment Or Project Page

Overview, requirements, deliverables, submission instructions, rubric, milestones. Start from assignment-page.md or project-brief.md.

Course Timeline

Week-by-week schedule, units, due dates, grading breakdown, anchor links. Start from course-timeline.md.

Course Homepage

Welcome message, module navigation, key dates, instructor contact, quick links. Start from homepage.md.

Media Gallery

Images, linked thumbnails, iframe embeds, and media notes using absolute URLs. Start from gallery-page.md.

Syllabus Or Course Info

Course description, meeting details, grading, schedule overview, policies, resources. Start from simple-syllabus.md.

Output Format Rules

  • Use HTML source, not a rendered visual preview.
  • Use an HTML fragment, not a full web page.
  • Use a downloadable source file or artifact when the AI tool supports it.
  • Use inline style="" attributes only.
  • Do not include html, head, body, style, script, or SVG.
  • If source appears in a code block, copy only the HTML inside the block. Do not paste backticks into Canvas.
  • Use absolute URLs for images and iframes.
  • Keep critical deadlines and instructions visible without requiring collapsible sections.
