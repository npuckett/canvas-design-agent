Getting Content Into Canvas

Three ways to move AI-generated pages and assignments into your Canvas course — from pasting a single page to building an entire semester in one import.

Overview

Which path should I use?

All three paths start the same way: an AI working from SKILL.md — either a web chat or a coding agent in a course repo — produces Canvas-safe HTML. The paths differ in how that HTML gets into your course, and how much each trip can carry.

PathCarriesSetup neededBest for
1. Copy & Paste One page or one assignment description at a time. No settings (points, due dates) — you set those in Canvas. None Single pages, quick fixes, workshops, trying things out
2. Course Package Import Everything at once: all pages, all assignments with points, due dates, submission types, and grading; assignment groups with grade weights; modules; syllabus; home page. None — uses the Import button you already have Building or restructuring a whole course; next semester's shell; bulk updates
3. Direct API Sync Pages, assignments, and syllabus — pushed instantly, no import step. A Canvas access token (some schools disable these — see below) Day-to-day edits after the course structure exists

A common pattern: build the course once with Path 2, then make small edits during the semester with Path 1 or Path 3 — whichever your school makes easier.

The recommended setup

The course repo: where the real workflow lives

There are two places you can work with the AI:

  • A web chat (Microsoft Copilot, ChatGPT, Claude in the browser) — you paste SKILL.md into the conversation, then paste content in and copy HTML out. Great for a first try and for one-off pages; nothing to install. But each conversation starts from scratch, and your course exists only as whatever you last pasted into Canvas.
  • A course repo with an AI coding agent (Claude Code, Cursor, VS Code with Copilot — any tool that edits files in a folder) — your course lives as a folder of small text files: one file per page, one per assignment, plus your grading scheme, module structure, and a style.md that captures your course's visual identity. The agent reads the skill and your style automatically and edits the files; the build tool turns the folder into a Canvas import.

For actually managing a course, the repo is the more reasonable workflow, because the files — not Canvas — become the source of truth:

  • Consistency for free — your customizations (theme, colors, recurring page sections) are saved in the repo, so every generated page matches without re-explaining anything.
  • Course-wide edits become one sentence — "shift all due dates a week later", "restyle every class page", "add a grading table to each assignment" — the agent edits many files, you review the diff, rebuild, re-import.
  • History and reuse — keep it in git and you get a record of every change, and next semester's course is a copy of the folder with new dates.

Start from the template

There's a ready-made template repository: canvas-course-template. It's self-contained — the skill file, the build tools, agent instructions (CLAUDE.md), a fillable style.md, and one starter page and assignment. Get your own copy:

  • On GitHub (recommended — gives you history and backup): open the template repo, click the green "Use this template" button → "Create a new repository", name it for your course, then clone it to your computer.
  • Without a GitHub account: download it as a ZIP and rename the folder, or run npx degit npuckett/canvas-course-template my-course.

Then open the folder in your coding tool and describe your course:

# open it in your AI coding tool and work in plain language:
#   "Set up style.md for a warm, approachable studio course."
#   "Create class pages for weeks 1-12 from my notes in notes.txt."
#   "Add Project 1: 100 points, letter grade, PDF upload, due Oct 7."

# then build and import (Path 2)
python3 tools/build_imscc.py . -o dist/course.imscc
No coding required. A course repo sounds technical, but the files are short and readable — settings at the top, page content below. The AI agent does the editing; you describe what you want and review the results. The template's README walks through setup step by step.
Path 1

Copy & Paste into the editor

The original workflow, and still the fastest way to get one good-looking page into Canvas. No installs, no permissions — if you can edit a Canvas page, you can do this.

Steps

  1. Open an AI chat (Microsoft Copilot, ChatGPT, or Claude) and paste in the contents of SKILL.md, or upload the file. Wait for its ready message.
  2. Paste your course content — rough notes, a syllabus section, an assignment description — and describe any style preferences.
  3. Copy the HTML source the AI produces (not the rendered preview).
  4. In Canvas, edit your page and click the HTML editor icon (</> at the bottom-right of the toolbar, or "html editor" in older Canvas versions).
  5. Paste, save, done.

Limits to know about

  • One page per trip. A 24-class course means 24 rounds of copy/paste.
  • Assignment settings — points, due dates, submission types, group weights — can't travel through the editor at all. You still click through Canvas's assignment forms for those. Path 2 removes exactly this limitation.
Path 2

Course Package Import — build a whole course in one import

Canvas has always been able to import a full "Course Export Package" (a .imscc file) — that's how courses get copied between semesters. The tools folder in this repository lets you build one of those packages yourself, from a plain folder of text files.

One import then creates (or updates) everything:

  • Every wiki page, including a designated course home page
  • Every assignment — description, points, due date, submission type (upload / URL / text), grading type (points, letter grade, pass/fail), file-type restrictions, group assignments
  • Assignment groups with percentage weights and drop-lowest rules — your whole grading scheme
  • Week-by-week modules with pages, assignments, text headers, and external links
  • The syllabus

What the source folder looks like

Each page or assignment is one markdown file: a few settings lines at the top, then the Canvas HTML below. You don't have to write these by hand — an AI agent working with SKILL.md can generate the whole folder from your course notes, and you review the files before building.

my-course/
├── course.md          course title, code, timezone
├── groups.md          grading scheme (a simple table of weights)
├── syllabus.md
├── modules.md         week-by-week structure
├── assignments/
│   ├── project-1.md   ← settings + HTML in one file
│   └── ...
└── pages/
    ├── class-1.md
    └── ...

A sample assignment file:

---
title: Project 1 - Proposal
group: Project 1
points: 100
grading_type: letter_grade
submission_types: online_upload
due: 2026-10-07 23:59
---

<h2>About</h2>
<p>Write a one-page proposal...</p>

Steps

  1. Start a course folder from the course repo template above (or from your existing course — see Updating a course in bulk below). The template includes the build tools — plain Python scripts that run on any Mac (built in) or Windows machine with Python 3.9+. Nothing else to install.
  2. Build the package: 
    python3 tools/build_imscc.py my-course
  3. In Canvas: Settings → Import Course Content → Content Type: "Canvas Course Export Package" → choose your .imscc file → All Content → Import. Canvas queues the import and finishes in a minute or two.
  4. Spot-check: Assignments (weights under the ⋮ menu → Assignment Groups Weight), a page or two, and Modules.
Re-importing updates, it doesn't duplicate. The builder gives every page and assignment a stable internal ID. Edit your markdown, rebuild, import again — Canvas updates the existing items in place. This is what makes the package path a real management workflow, not just a one-time setup.
No special permission required. This path uses the same Import Course Content button teachers already use to copy courses between semesters. If your school locks that down (rare), your teaching & learning centre can run the import for you.

Full format reference: tools/README.md · Worked example: tools/example-course

Path 3

Direct API Sync — no import step at all

Canvas has a REST API — the same interface its own apps use. With an access token, the canvas_api_sync.py tool pushes a page or assignment straight into your course from the command line: edit a file, run one command, refresh your browser.

First: does your school allow it?

The API itself is always on; what schools control is whether you can create an access token. Check in two minutes:

  1. In Canvas, go to Account → Settings and scroll to Approved Integrations.
  2. Look for a "+ New Access Token" button below the table of apps.
  3. Button there? You can use this path — create a token, give it a purpose ("course sync") and an expiry date, and copy it somewhere safe. Treat it like a password: it grants full access to your Canvas account.
  4. No button? Your institution has disabled self-service tokens (many do). You can ask IT for one, but Path 2 covers nearly everything this path does — you lose very little.

Steps

export CANVAS_API_TOKEN="paste-your-token-here"
python3 tools/canvas_api_sync.py my-course \
    --base-url https://canvas.yourschool.edu \
    --course-id 12345

The course ID is the number in your course's URL. Add --only pages/class-3.md to push a single file, or --dry-run to preview exactly what would be sent without sending anything.

Limits to know about

  • Creates and updates pages, assignments, and the syllabus — but not assignment groups, grade weights, or modules. Do the course structure with Path 2 first.
  • Assignments are matched by exact title, so renaming one in your files creates a new one rather than updating. (Path 2 is immune to this.)
  • Test on a sandbox course first, and prefer tokens with an expiry date.
Management

Updating a course in bulk

The package tools work in both directions, which unlocks course-wide edits that would be painful to click through:

  1. Export your existing course: Canvas → Settings → Export Course Content → "Course" → download the .imscc.
  2. Extract it into an editable folder: 
    python3 tools/extract_imscc.py my-export.imscc -o my-course
    Every page and assignment becomes a small markdown file with its settings at the top.
  3. Edit — by hand, or by handing the folder to an AI agent with SKILL.md: "restyle every class page with the Studio Dark theme", "shift all due dates one week later", "add a rubric section to every Workshop assignment".
  4. Rebuild and import: 
    python3 tools/build_imscc.py my-course
One caveat on the round trip. Extracting an export assigns fresh internal IDs, so importing a rebuilt package back into the same live course creates copies alongside the originals. The round trip shines for populating a new course shell — next semester's section, a sandbox, a redesigned version. Once a course is managed from a source folder, repeated rebuild-and-import cycles into that course update cleanly in place.
