Method 1: Web Chat

This is the recommended first workflow for workshops and occasional use. It works with Microsoft Copilot, ChatGPT, Claude, or another AI chat that can read an uploaded or pasted markdown file.

Download SKILL.md View Downloads
  1. Download the skill file. Save SKILL.md from the button above.
  2. Open a new AI chat. Use Microsoft Copilot if that is the supported tool for your institution. ChatGPT and Claude can follow the same pattern.
  3. Upload or paste the skill. If upload is not available, open SKILL.md, copy all text, and paste it into the chat.
  4. Paste your course content. Rough notes, syllabus text, assignment descriptions, or weekly module content are all acceptable.
  5. Ask for a Canvas fragment. Use the prompt below, then let the agent generate the page.
  6. Copy the HTML fragment. Copy only the generated HTML, not any surrounding explanation.
  7. Paste into Canvas. Open the Canvas Rich Content Editor, switch to HTML view, paste, save, and review.
Use the uploaded Canvas Design Agent skill. Transform my course content into a Canvas-ready HTML fragment using inline styles only. Do not include html, head, body, style, script, SVG, or markdown code fences.

Method 2: Prompt File Workflow

Use this method when you want a reusable source file for a page. The prompt file becomes your editable course material, and the generated HTML becomes the paste-ready Canvas output.

Download SKILL.md Browse Prompt Templates
  1. Download the skill file. Keep it with your course materials or upload it into the chat each time.
  2. Choose a prompt template. Start from a template in Downloads or write a new markdown file.
  3. Replace the sample content. Keep the headings and output expectations, but swap in your course material.
  4. Generate the Canvas HTML. Give the prompt file and SKILL.md to the AI agent and ask for a Canvas HTML fragment.
  5. Review and save both versions. Keep the prompt file as the source, and keep the generated HTML if you want a record of what was pasted.
  6. Revise by editing the prompt. When the course changes, update the markdown source and regenerate.

Best for: weekly pages, assignment templates, project briefs, syllabi, schedules, or any page that will be revised and reused.

Method 3: Local AI Editor

This method is useful when you manage many course files locally and want prompt files, generated HTML, examples, and notes in the same project folder.

Download SKILL.md Guide Summary
  1. Download or clone the project. You can use the full repository or just place SKILL.md wherever your AI editor expects reusable instructions.
  2. Create course prompt files. Store each page as a markdown prompt, such as week-03-module.md or project-01-brief.md.
  3. Ask the local agent to transform the prompt. Reference the skill and the prompt file in the same request.
  4. Preview the output. Open generated HTML locally when possible, then make targeted revisions in the prompt.
  5. Paste the final fragment into Canvas. The same Canvas constraints apply: inline styles only, no full document wrapper.

Best for: faculty who are already comfortable in a code editor or who want versioned course content over multiple semesters.

Method 4: Component Sketching

Use component sketching when you are not sure how a schedule, rubric, resource list, callout, or other small piece of content should appear. Instead of asking for a complete page immediately, ask the agent to compare a few Canvas-safe options.

Download SKILL.md See Component Example
  1. Download or upload the skill. Component sketching is described inside SKILL.md.
  2. Paste one focused content problem. Use schedule data, a grading breakdown, a resource list, or a short note rather than a full course page.
  3. Ask for options. Request 3-4 Canvas-safe sketches with visible tags such as OPTION-A: D05-S01 Schedule Grid.
  4. Choose or revise one option. Ask for changes by tag, combine options, or ask the agent to use a selected option in a complete page.
  5. Generate the full page when ready. Switch back to the full-page workflow and reference the chosen option tag.
Use the Canvas Design Agent skill in Component Sketching Mode. Show 3-4 Canvas-safe options for the content below. Give each option a reusable tag, make every option inline-styled HTML, and keep the output compatible with Canvas.

Method 5: Canvas Paste And Review

This method is the final quality check for every workflow. Canvas is the real test because the Rich Content Editor sanitizes HTML when you save.

Download SKILL.md Troubleshooting
  1. Before pasting, scan the output. Confirm there are no markdown fences, html, head, body, style, or script tags.
  2. Open the Canvas HTML editor. In the Rich Content Editor toolbar, use the </> HTML editor control, often inside the more-options menu.
  3. Paste and save. Paste the fragment, save the page, and reopen it if needed.
  4. Check what survived. Confirm formatting remains visible, links work, images load, and collapsible sections open when clicked.
  5. Revise with a follow-up prompt. If Canvas strips something, paste the problem area back into the AI chat and ask for Canvas-safe inline HTML only.
