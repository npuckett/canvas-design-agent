How it works

From notes to a live course

01

Canvas has strict rules

The Canvas editor strips style blocks, scripts, SVG, and many CSS properties. Most nice-looking HTML dies on paste.

02

This project encodes them

A catalog of 51 elements and 7 themes that all survive Canvas — used as the Designer's palette and as the AI's instruction set (SKILL.md).

03

You create, either way

Click blocks together in the Designer, or describe pages to an AI. Your course accumulates as readable files you can keep in git.

04

One import, everything in

Build a Canvas Course Export Package: all pages, assignments with points and due dates, weighted grading groups, modules, and the syllabus. Re-import to update in place.

The shared vocabulary

Element categories

Every element has an ID. In the Designer they're the palette; with an AI you can name them ("use C01 for the resources section") or just describe what you want.

LLayout — columns, flexbox, CSS grid, containers CContent — collapsibles, cards, definition lists, checklists TTypography — headings, highlights, blockquotes, keyboard shortcuts DData — tables, schedule grids, comparison tables, progress bars VVisual — accent boxes, color headers, alerts, badges, gradients NNavigation — anchor links, button-styled links XCanvas — assignment links, file embeds, video/audio players EExternal media — images, iframes, embedded sketches SStyle themes — seven complete visual identities FFont stacks — five Canvas-safe typeface sets
