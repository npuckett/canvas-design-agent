Example: Component Sketches

A comparison output that shows several smaller Canvas-safe element options before choosing one for a complete page.

About This Example

This page demonstrates the optional Component Sketching Mode. Instead of generating one final course page, the agent analyzes a specific display problem and returns several tagged HTML options in a row for comparison.

Sample request: "Show me 3-4 ways to display a 10-week course schedule with due dates on Fridays. Tag each option so I can reference it later."

Elements Used

  • S01 Clean Modern Theme
  • S03 Warm Minimal Theme
  • D05 Schedule Grid
  • D01 Data Table
  • L03 Flexbox Row
  • C03 Info Card

How to replicate: Ask for Component Sketching Mode and describe one data type at a time. After reviewing the output, say something like "Use OPTION-B for the schedule section in my course homepage" or "Make OPTION-C more compact."

Canvas Preview

This preview shows a single Canvas HTML fragment containing four tagged options. A faculty member can copy one option later or reference its tag in a full-page request.

Schedule Display Sketches
