About

About this project and its author.

This project was developed by Nick Puckett, Associate Professor at OCAD University.

Canvas Design Agent grew out of the practical challenge of creating well-designed, consistently formatted course pages in Canvas LMS without writing HTML by hand. It began as a portable skill file that teaches AI tools what Canvas will and won't render, and has grown into a full system: the same element catalog now powers both an AI workflow (SKILL.md plus course-building tools) and a visual editor (the Canvas Designer app) — two ways of creating the same plain-file course format.

This project can be used, modified, or extended freely and openly for academic purposes.

Compatibility note: everything targets Canvas LMS Rich Content Editor pages using inline styles and Canvas-safe HTML fragments. Canvas behavior can vary by institution, especially for iframe embeds and external media domains. Test generated pages in a Canvas sandbox before sharing them with students.
