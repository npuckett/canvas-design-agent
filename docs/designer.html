Why it exists

The Canvas editor, without the Canvas limits

Canvas's built-in editor works on one page at a time, silently strips most styling, and keeps assignment settings in separate forms scattered across the site. Canvas Designer flips that: your whole course is open at once as a folder of plain files, every block you insert is guaranteed to survive the Canvas sanitizer, and pages, assignment settings, grading groups, and modules travel into Canvas together in one import.

It's also the visual half of this project's two creation methods: the Designer and the AI agent workflow read and write the same files, so you can start a course with one and continue with the other.

Features

What you can do

Block editing

Every page is a stack of blocks. Click to select, type to edit text in place, reorder, duplicate, or open any block's raw HTML.

Nested layouts

Click inside a block to select a column, card body, or collapsible's content — a breadcrumb shows where you are, and inserts land inside the selected container.

Full element palette

The complete catalog — 51 elements, 82 variants — with live previews that follow your active theme. What you insert is exactly the catalog HTML.

Themes & course styles

Switch a page between the seven standard themes with one dropdown, or design your own: nine color roles, font, corner radius, header gradient — saved as a named course style.

Assignment settings as a form

Points, due dates, submission types, grading type, assignment group — the settings Canvas hides in forms, edited right next to the page content.

Canvas-safety checker

A deterministic check of the Canvas sanitizer's rules. Palette blocks pass by construction; the checker guards anything hand-edited.

One-click build

Produces a Canvas Course Export Package (.imscc) with pages, assignments, weighted grading groups, modules, and syllabus. Re-imports update in place.

New course scaffolding

Start a fresh course from the welcome screen — it creates the folder structure for you — or open any existing course repo, including agent-generated ones.

On Windows, Linux, or without installing anything

The app is a shell around a single dependency-free Python script that's included in every course repo made from the course template. From your course folder, run:

python3 tools/designer.py .

It starts a local-only server and opens the same editor in your browser. Any Python 3.9+ works; nothing is installed and nothing leaves your machine.

Interop

Plays well with the AI workflow

Because the Designer edits the same course folder the agent workflow uses, the two combine naturally:

  • Agent drafts, you polish. Have an AI generate a semester of pages from your notes, then fine-tune layout and wording visually.
  • You design, agent scales. Build one class page you love in the Designer, then ask an agent to "make pages for weeks 2–12 in the same structure."
  • Custom styles carry over. Styles you create in the Designer are saved to a machine-readable styles.json, and the agent instructions tell AI tools to honor your default style instead of inventing colors.
Everything stays local. The Designer has no accounts, no cloud, and no AI calls — it reads and writes files in your course folder, full stop. Using an AI agent on the same folder is always your choice, made in your own AI tool.
