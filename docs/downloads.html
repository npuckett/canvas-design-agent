The skill file, prompt templates, and course-building tools — everything you need for each of the three workflows.

The Skill File

The one file every workflow starts with. Paste or upload it into Microsoft Copilot, ChatGPT, or Claude; it teaches the AI Canvas's rules and the element library, then waits for your course content.

SKILL.md

The complete Canvas Design Agent instruction set: Canvas constraints, the numbered element library, style themes, accessibility rules, and output checks.

Right-click → Save Link As… if your browser opens it as text · Used in: all workflows
Tip: In most AI chats you can simply paste the file's entire contents as your first message — the file opens with instructions that tell the AI what to do. It replies when it's ready for your course content.

Prompt Templates

Markdown starting points for common Canvas page types. Open one, replace the content with your own, and paste it into a chat that has the skill loaded. Each generates a page like the ones on the Examples page.

Simple Syllabus (best first try)
