AI method

The skill file

The file the AI method starts with. Paste or upload it into Microsoft Copilot, ChatGPT, or Claude; it teaches the AI Canvas's rules and the element library, then waits for your course content.

SKILL.md

The complete instruction set: Canvas constraints, the numbered element library, style themes, accessibility rules, and output checks.

Right-click → Save Link As… if your browser opens it as text · Used in all AI workflows
Tip: in most AI chats you can simply paste the file's entire contents as your first message — it opens with instructions that tell the AI what to do, and the AI replies when it's ready for your content.

Prompt templates

Markdown starting points for common Canvas page types. Open one, replace the content with your own, and paste it into a chat that has the skill loaded. Each generates a page like the ones on the Examples page.

Course folder & tools

Course repo template (recommended starting point)

A self-contained template for managing a whole course as files: the Designer script, build tools, skill file, AI agent instructions, a fillable course style file, and starter content. Click "Use this template" on GitHub, or download it as a ZIP.
