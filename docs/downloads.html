How To Use These Files

  • Download SKILL.md and upload or paste it into your AI chat first.
  • Choose a prompt template that matches the kind of Canvas page you want.
  • Replace the sample course content with your own material.
  • Ask for a Canvas HTML fragment with inline styles only.
  • Paste the generated fragment into the Canvas Rich Content Editor HTML view.

Not sure where to start? Use the web chat method for a first page, then come back for prompt templates when you want a repeatable workflow.
